# Rasul Akhmetov — Portfolio

Static scroll-controlled portfolio with RU / KZ / EN, WhatsApp and Telegram links.

## GitHub Pages

1. Upload `index.html` and `.nojekyll` to the root of the publishing branch.
2. In repository Settings > Pages, choose **Deploy from a branch**, select the branch and `/ (root)` folder, then Save.
3. The site URL for repository `zephyr363/rasul-portfolio` will normally be `https://zephyr363.github.io/rasul-portfolio/`.

All frames are embedded in index.html, so no build tool or asset directory is required.
