# Переработка дизайна: Serif

Новый дизайн реализован по пользовательскому промпту от 18.10.2026. Существующий стек React Router SSR, TypeScript, Django и RTK Query сохранён.

## Изменения

- Единые CSS-токены: ivory #FAFAF8, rich black #1A1A1A, warm gray #6B6B6B, gold #B8860B и тонкие разделители #E8E4DF. Для мелкого текста и белого текста кнопок применяются более тёмные оттенки золотого для контрастности.
- Локальные Playfair Display, Source Sans 3 и IBM Plex Mono с кириллицей. Шрифты не загружаются со стороннего CDN и используют font-display: swap.
- Вместо крупного BACKEND и модельной композиции — понятное предложение клиенту, знакомство с разработчиком, три направления помощи, личный подход, опыт и технологии.
- Удалены публичные страницы `/portfolio`, `/portfolio/:slug`, ссылки на фотогалерею и её React-компонент. Старые страницы отвечают 404. Исходные референсы в базе сохранены; новый лендинг использует отдельные поля портретов в настройках сайта.
- Заголовок, предложение клиенту и оба портрета редактируются в «Настройки сайта → Лендинг». Модель Service позволяет менять названия, описания, технологии, порядок и публикацию направлений работы.
- Два обработанных портрета экспортированы с длинной стороной 2048 px. Происхождение и точные промпты: `portrait-prompts.md`.
- Внутренние страницы, формы и кабинет получили ту же типографику, цвета, поля и кнопки. Авторизация и сохранение заявок продолжают работать через существующий API.

## Обновление существующей установки

После установки frontend-зависимостей и применения миграций выполните:

```powershell
. .\scripts\env.ps1
cd backend
uv run python manage.py migrate
uv run python manage.py configure_landing
```

Команда заполняет только пустые поля лендинга и отсутствующие направления работы. Новые изображения находятся в seed_media и копируются в media через штатное файловое хранилище Django. Портреты после этого можно менять через CMS.

## Проверка

Проверяются отсутствие фотогалереи, SSR, адреса и размер портретов, отображение направлений работы, переход к контакту, мобильная навигация, форма и авторизация. Скриншоты: `.runtime/serif-first-screen.png`, `.runtime/serif-desktop.png`, `.runtime/serif-mobile.png`.

Проверено фактически: 5 Playwright-сценариев, 5 Vitest-тестов авторизации и 2 новых backend-теста CMS прошли. Strict TypeScript, Ruff, Django check, проверка миграций и validation OpenAPI прошли. Backend и frontend Docker-образы собраны. На ширинах 375, 768, 1440 и 1920 px переполнений нет; naturalHeight обоих портретов — 2048 px. Тестовые заявки удалены после проверки.
